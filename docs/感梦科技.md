     
        # 内网网盘系统开发需求文档
     
       
         
       
       
        ## 一、项目概述
       
       
        构建支持远程存储（MinIO/OSS）、微信扫码登录的内网网盘系统，支持图片、视频、EXE、压缩包存储，具备个人区与公共区（全域/部门）隔离、断点续传、秒传、快速搜索、病毒扫描、人员权限管理等功能。
       
       
         
       
       
        ## 二、技术栈
       
       
        | 层级 | 选型 |
       
       
        |---|---|
       
       
        | 后端 | Go（高并发上传/转码） |
       
       
        | 前端 | Vue3 + ElementPlus |
       
       
        | 存储 | MinIO（内网自建） |
       
       
        | 数据库 | MySQL + Redis |
       
       
        | 搜索 | Meilisearch |
       
       
        | 视频 | FFmpeg 异步转码 |
       
       
        | 杀毒 | ClamAV |
       
       
         
       
       
        ## 三、核心模块
       
       
         
       
       
        ### 1. 人员与权限管理
       
       
        - **组织架构**：支持部门/子部门多级树形结构
       
       
        - **角色体系**：超级管理员、部门管理员、普通用户、访客
       
       
        - **微信扫码登录**：OAuth2 回调绑定本地账号，JWT 鉴权
       
       
        - **权限控制**：RBAC 模型，支持按用户/部门授权
       
       
         
       
       
        ### 2. 存储区域划分
       
       
        - **个人区**：仅本人和管理员可见，配额可配置
       
       
        - **公共区-全域**：全公司可见，需管理员审核发布
       
       
        - **公共区-部门**：仅本部门成员可见，部门管理员审核
       
       
        - **EXE/压缩包**：单独 `software` 桶，默认不公开，下载前杀毒
       
       
         
       
       
        ### 3. 上传模块
       
       
        - 分片上传（5MB/片）、断点续传、秒传（SHA256）
       
       
        - 3-5 分片并发，实时进度展示
       
       
        - 白名单校验（扩展名+MIME+文件头）
       
       
        - 单文件 ≤ 10GB，压缩包防炸弹（层数/文件数/体积限制）
       
       
        - 上传后异步触发 ClamAV 扫描，异常文件隔离
       
       
        - 上传日志：用户、文件名、大小、结果、耗时
       
       
         
       
       
        ### 4. 搜索模块
       
       
        - Meilisearch 索引文件名、类型、标签、上传者
       
       
        - 支持模糊搜索、拼音、错别字容错
       
       
        - 按类型/用户/目录/区域过滤，按相关度/时间/大小排序
       
       
        - 搜索结果高亮，权限校验后生成预签名 URL
       
       
         
       
       
        ### 5. 视频处理
       
       
        - 上传后 MQ 触发 FFmpeg 转码多分辨率 HLS
       
       
        - 生成封面图，支持在线播放
       
       
         
       
       
        ### 6. 公共区管理
       
       
        - 全域资源管理员审核，部门资源部门管理员审核
       
       
        - EXE 禁止放入公共区
       
       
        - 支持分享链接+提取码+有效期
       
       
        - Referer 防盗链，敏感文件预签名 URL（30分钟有效）
       
       
         
       
       
        ## 四、接口清单
       
       
        | 接口 | 方法 | 说明 |
       
       
        |---|---|---|
       
       
        | `/auth/wechat/login` | GET | 微信扫码登录入口 |
       
       
        | `/auth/wechat/callback` | GET | 微信回调绑定 |
       
       
        | `/user/list` | GET | 人员列表（管理员） |
       
       
        | `/user/create` | POST | 新增用户 |
       
       
        | `/dept/tree` | GET | 部门树 |
       
       
        | `/upload/init` | POST | 初始化上传 |
       
       
        | `/upload/chunk` | POST | 上传分片 |
       
       
        | `/upload/merge` | POST | 合并分片 |
       
       
        | `/upload/status` | GET | 查询进度 |
       
       
        | `/file/search` | GET | 文件搜索 |
       
       
        | `/file/share` | POST | 生成分享链接 |
       
       
        | `/public/apply` | POST | 申请发布到公共区 |
       
       
        | `/public/approve` | POST | 审核公共区文件 |
       
       
         
       
       
        ## 五、部署架构
       
       
        - MinIO 建 `personal`、`public-global`、`public-dept`、`software` 四个桶
       
       
        - Nginx 反代 443/SSL，`/public/` 路径对外暴露，Console 管理口不对外
       
       
        - 无公网 IP 时使用 frp 内网穿透
       
       
        - 上传/转码/杀毒/索引全部异步化，Redis + MQ 解耦
