# 本地演示说明

当前阶段只在开发电脑演示，正式部署须等本地验收确认。演示监听 `127.0.0.1:18080`，只允许本机访问；真实资料仍在另一台电脑，尚未扫描或迁移。

## 打开演示

浏览器访问 `http://127.0.0.1:18080`。本机测试账号见 [.local/开发预览账号.txt](../.local/开发预览账号.txt)，这些账号只用于虚构演示，不能复制到正式环境。

若服务未启动，在项目目录运行 [.local/start-preview.ps1](../.local/start-preview.ps1)。脚本启动本项目独立的 13386 端口开发数据库和页面服务，请保持启动脚本所在终端运行。

## 建议验收顺序

1. 使用超管查看公司空间中的“公司制度”“培训资料”“项目资料”和“历史资料”。在搜索栏输入“入职”“报销”“界面示例”，检查文件名及备注命中。
2. 进入文件详情，修改备注并再次搜索；新上传文件时为每个文件填写备注，检查上传后的显示和搜索。
3. 用综合部员工查看部门空间，再换技术部账号查看部门空间，两者不能互相看到对方部门资料。
4. 给综合部员工个人空间上传测试文件；换超管或维护管理员，可选择员工并管理；换部门管理员则不应看到该员工的个人文件。
5. 使用普通员工向公司空间提交文件，再切换超管在发布审核中处理。
6. 将自己有权管理的测试文件移入回收站并恢复；恢复文件夹不会恢复之前单独删除的文件。
7. 进入公司资料扫描页面扫描开发测试目录，再次扫描应不重复登记；改过的名称和备注继续保留。

公司包含综合管理部和产品技术部。账号有超管、维护管理员、综合部管理员、综合部员工、技术部管理员，均为虚构身份。公司资料、两个部门的资料以及各账号的个人资料相互独立。

## 多主题与后台配置

当前运行地址仍为 `http://127.0.0.1:18080/`。`18081` 是此前的两版交互原型，实际功能请在 `18080` 验收。

1. 右上角主题选择提供目录工作台（A）、影像资料库（B）、清爽协作及跟随站点默认。切换后刷新验证个人选择仍保留。
2. 公司空间使用左侧目录树、面包屑和上一级按钮浏览。“全部 / 文件 / 视频 / 压缩包”保留目录入口；勾选“包含子目录”后，可在公司根目录搜索“报销”等备注。历史资料仍由管理员扫描登记。
3. 管理员进入“站点配置→站点与目录”，可保存公司名称、简称、Logo、默认主题、服务器目录和版权。Logo 已使用临时测试图片验证上传、加载和恢复默认图标；正式 Logo 待用户提供。
4. “站点配置→短信配置”可设置开关、平台地址、AK（AppKey）、SK（AppSecret）和模板标识 templateKey。凭证输入留空保留，显式清除需先关闭；保存不发送短信。本地当前保持关闭，无真实项目凭证。
5. 底部版权已关联 `https://www.gmkj.cc/`。目录变更需重启，已有上传文件或历史索引时拦截直接切换，避免文件失联。本地的路径仅为演示路径，不是正式部署路径。

## 本轮验收

超管可配置统一文件根目录和容量告警阈值，站点部署目录只读。维护管理员可管理全部空间、人员、扫描和日志，但不能进入站点配置或管理超管。个人、部门空间提供管理员归属选择。可上传文件夹并回收、恢复整个目录；回收不会释放磁盘容量。磁盘容量来自当前文件根目录所在磁盘，默认低于 10% 提醒维护。

## 目录和图片验收

“上传文件 / 文件夹”中可选择目录，批次上限 500 文件、2 GiB、32 层、1000 项目。目录行或卡片点“下载目录”生成 ZIP，保留层级；服务器每次处理一个任务，大目录分批下载。公司空间图片行点“预览”，也可直接点图片名称；弹窗右上角“下载原文件”保存图片。待检查或无权限文件不能下载、预览或绕过 ZIP 获取。

## 同目录批量操作补充

表格提供勾选框，“移入回收站”直接位于下载旁，不再藏于下拉菜单；卡片同样提供勾选与直接操作。选择仅限当前页，换目录、查询、刷新、切换主题或列表视图后清空，避免误操作。

- 批量移入回收站允许混选文件和目录，所选目录内子项递归处理，原磁盘文件保留。最多选择 500 个直接项目，包含子项合计最多 10000 项。有任意项目无管理权或状态变化时整批拒绝，不发生部分删除；之前已回收的子项保留其原状态。
- 批量下载仅接受同一目录内的文件，生成“批量文件.zip”；最多 500 文件、合计 2 GiB。选中目录或包含不同目录的搜索结果时按钮禁用，服务端也会拒绝。选中不可下载文件时须先完成安全检查。
- 不能批量打包多个目录。每个目录行的“下载目录”可独立打包该目录及其子目录，沿用前文 ZIP 限制、权限和清理规则。
