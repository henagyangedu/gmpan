# GmPan 感梦企业网盘｜内网文件管理与文件共享系统

GmPan 感梦企业网盘是支持私有化部署的内网文件管理与文件共享系统，适用于企业内网管理。采用 Go、Vue3、Element Plus、MySQL 和本地文件存储，支持公司、部门、个人三个空间及权限控制、目录上传下载、图片在线预览、视频在线播放与下载、文件名和备注搜索、已有文件扫描登记、分片断点续传、发布审核、回收站和操作日志。支持用户名或手机号密码登录，接入短信平台后可启用短信验证码登录。

适合在公司内网统一管理制度文档、培训视频、图片、软件与项目交付包。员工通过浏览器访问，文件保存在自己的服务器上；不要求服务器具备公网 IP。短信登录为可选功能，需要服务器能够主动访问短信平台。

## 主要功能

- **三个资源空间**：公司资料发布后全员可见；部门资料限本部门；个人资料限本人。超管和维护管理员可查看、管理所有空间。
- **保留已有目录**：扫描指定存储目录及子目录，按原层级登记到公司空间，不搬动磁盘原文件；新增登记内容默认公开。
- **文件与目录上传**：分片续传、逐文件备注、文件夹层级保留；文件名或备注包含关键词即可命中搜索。
- **预览与下载**：兼容图片、PDF、音视频在线预览；单文件下载、同目录文件批量 ZIP 下载、单个目录连同子目录 ZIP 下载。
- **发布与回收**：共享文件审核、单项或批量移入回收站、误删恢复。回收是软删除，不释放磁盘空间。
- **多主题**：目录工作台、影像资料库、清爽协作，支持站点默认和个人浏览器偏好。
- **管理员后台**：人员与部门、配额、资料扫描、操作日志；超管另可配置公司名称、简称、Logo、目录、版权、容量告警及短信。
- **内网部署**：Go 单程序内嵌前端，MySQL 保存业务数据，本地磁盘保存文件；病毒检查可选不启用、立即或定时模式，由超管在后台设置。

当前不提供公网匿名分享、在线解压、Office 在线编辑、视频转码或文件内容全文检索。兼容性取决于浏览器和文件编码；不兼容格式可下载原文件。

## Windows 部署方法

### 1. 准备环境与构建部署包

本仓库提供源码；没有现成部署包时，在 Windows 构建电脑安装 Go 1.26 或更新版本、Node.js 22.12 或更新版本及 npm。最低要求分别见 `go.mod` 和前端构建依赖。构建时需要下载 Go / npm 依赖；部署电脑不需要安装 Go、Node.js。

```powershell
git clone https://gitee.com/lyhcms/gmpan.git
Set-Location .\gmpan
.\scripts\build.ps1
```

也可从 [GitHub 仓库](https://github.com/henagyangedu/gmpan)获取源码。脚本安装前端依赖、构建前端、执行 Go 测试并生成 `release/GmPan`。将**整个目录**复制到部署电脑，例如 `D:\GmPan`，保留其中的手册与 `images` 配图目录。

### 2. 准备数据库、文件盘与安全检查

创建 GmPan 专用的空 MySQL 数据库和账号，勿与其他项目混用。另准备文件根目录、日志目录；启用病毒检查时需 ClamAV 及有效病毒库。数据库 SQL、目录权限和完整依赖配置见[部署手册第二至六节](docs/系统部署操作手册.md)。

程序目录与文件目录分开，例如程序放 `D:\GmPan`、文件放 `E:\公司资料`。文件根目录中的已有资料首次扫描后会公开给员工，先检查目录内没有私有资料、配置或密钥。内部 `.gmpan` 目录由系统管理，不向员工开放磁盘共享。

### 3. 配置与初始化

在部署目录中复制配置示例，按实际环境修改数据库、路径、监听地址、HTTPS 和 ClamAV 配置：

```powershell
Set-Location D:\GmPan
Copy-Item .\config.example.json .\config.json
```

仅本机试用可监听 `127.0.0.1:18080`。员工通过内网访问时，需配置实际内网 IP 或域名及可信任的 HTTPS 证书。程序支持生成内网自签证书，但须先在客户端建立信任，详见[部署手册第四节](docs/系统部署操作手册.md)。

```powershell
.\gmpan.exe migrate -config .\config.json
.\init-admin.ps1 -Username admin
.\start.ps1
```

管理员密码由脚本交互输入，没有统一默认密码。只有空用户表能初始化首个超管。确认配置正确后再执行初始化，勿使用其他业务数据库。

### 4. 登录、导入与验收

打开实际监听地址，访问 `/api/health` 应返回 `status=ok`。超管登录后先创建部门、员工，检查站点目录，再进入“公司资料扫描”登记已有资料。立即检查模式下，文件通过安全检查后才能下载或预览；不启用或定时模式允许访问未检查文件，并标注“未执行病毒检查”。

至少验证一次普通员工登录、公司文件下载、部门隔离、个人空间隔离、目录上传与下载，以及回收后恢复。验证通过后，再按[部署手册第十节](docs/系统部署操作手册.md)注册 Windows 服务、配置专用服务账号和内网防火墙。

服务需能够访问 MySQL；采用短信登录或在线更新病毒库时，还需对应的出站网络。应用本身不依赖公网登录回调，不需要端口映射。

## 使用限制与维护提醒

| 项目 | 当前规则 |
| --- | --- |
| 普通单文件上传 | 默认最大 10 GiB，可在配置中调整；仍受安全扫描能力限制 |
| 目录上传 / 单目录 ZIP 下载 | 最多 500 个文件、合计 2 GiB、32 层、1000 个文件及目录项目 |
| 批量下载文件 | 同一目录，最多 500 个文件、合计 2 GiB；不支持批量下载多个目录 |
| ZIP 下载并发 | 全服务器一次一个打包或下载任务；临时取件链接五分钟、本人一次有效 |
| 批量回收 | 最多选 500 项，包含子项合计最多 10000 项；无权管理时整批拒绝 |
| 未完成上传 | 保留 48 小时，选择原文件继续上传 |
| 可用空间告警 | 默认低于 10% 提醒，可由超管设为 1～99%；回收不会释放磁盘 |
| 历史目录更新 | 管理员手动再次扫描，不自动监控磁盘新增或变化 |

ClamAV 当前调用存在扫描大小及递归限制；**上传上限不等于可安全检查并下载的文件上限**。已发现威胁或检查失败的文件继续阻止访问；超管选择“不启用”或“定时检查”后，仅尚未完成检查的文件可按权限访问，并明确标注未检查。实际部署前请阅读[部署手册的扫描限制说明](docs/系统部署操作手册.md)。

## 开发验证

当前开发验证使用独立的 MySQL 5.7.40 实例；这不代表建议在新生产环境使用该旧版本。部署应选择符合组织维护要求的数据库版本，并在目标环境完成验收。

普通 `go test ./...` 运行不依赖数据库的测试。完整集成测试需专用测试实例：`GMPAN_TEST_DSN` 指向本项目隔离的 `127.0.0.1:13386` 且数据库名留空；测试自行创建并清理随机 `gmpan_test_` 数据库。该变量不允许指向生产数据库或其他项目实例。
